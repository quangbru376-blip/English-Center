# English Center Management System

Workspace for a university final project: a responsive Vietnamese web
application for managing an English language center.

The workspace currently contains requirements and agent instructions, but no
application source code yet. Start with [AGENTS.md](AGENTS.md), then read the
project memory under [`docs/`](docs/).

Owner-supplied directive files live in [`instructions/`](instructions/). This
directory is an input inbox, not the application source tree. Project Memory
records which inputs have been adopted and links to them without duplication.

The canonical product specification is [`docs/requirements.md`](docs/requirements.md).
The official Word report remains unchanged; its source and adopted corrections
are recorded in [`REPORT_BASELINE.md`](docs/reference/REPORT_BASELINE.md).
Project-local skills live in `.agents/skills/`.
