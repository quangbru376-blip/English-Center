# D13 and A01 walkthrough
The catalog inspector reads the caller connection and compares every pinned fact.
It keeps caller transactions intact, uses cancellation and a finite command timeout.
Hidden, missing or changed facts fail closed; operator compatibility is not runtime readiness.
EF tests cover identity/RV fetch and rollback on all five trigger tables.
Audit entries are immutable snapshots projected from accepted action/entity field allowlists.
Mandatory audit uses the existing business connection and transaction and never commits it.
An audit failure propagates safely; the caller must roll back the complete operation.
Pure security audit uses a separately supplied store and cannot undo logout/access checks.
Persistence failure increments one of four fixed, thread-safe numeric counters.
Security events/IP expire after90days; mandatory events have no expiry or IP by default.
Replay/no-op suppression, real auth/callers, cleanup and runtime configuration remain later work.
