# U01 HTTP and RAM session state
HttpClient sends only explicit fixed auth requests using same-origin cookies.
No request runs until called; no provider or route is mounted.
Unsafe requests need a RAM CSRF token; errors distinguish credentials/session/CSRF.
RequestScope aborts and rejects old-session or superseded responses.
AuthState holds exactly9context fields and CSRF in instance-owned RAM.
Login creates an explicit new boundary even for the same account.
Current401/logout/password or unknown auth writes clear local authority and cleanup hooks.
Unknown means server outcome unconfirmed; it never means rollback or successful logout.
CSRF recovery deliberately probes me/token; no automatic write/credential retry.
Existing endpoints: csrf/me GET; register/login/logout/change-password POST.
No storage, JWT parsing, PII URL, retry cache, timer, cross-tab transport or backend change.
Codex24 combined tests/typecheck/lint/build PASS; real runtime remains deferred.
