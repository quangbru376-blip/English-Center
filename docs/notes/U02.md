# U02 controls and shell
Shared native inputs/buttons preserve raw values and caller props.
Feedback separates loading, empty, no matches, errors and success.
Tokens supply system fonts, contrast and reduced-motion behavior.
IdentityShell composes the unavailable-functionality page without API calls.
Native dialog names its heading, traps Tab, closes by Escape/backdrop/button,
and restores opener focus; callers own confirmation content.
Synthetic browser fixture is dev verification only, outside production entry.
Codex:6 component tests and three-width browser checks PASS; build/lint/types PASS.
No backend runtime, business page, SQL, package or authenticated menu activated.
