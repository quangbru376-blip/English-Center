# V01-D
Edge chạy UI thật và gửi API tương đối qua HTTPS loopback với pin chứng thư riêng.
Node giữ khóa TLS trong RAM; chuyển nguyên Origin/cookie đến Kestrel loopback.
Kestrel chỉ nhận kênh có nonce RAM đúng, rồi dùng framework CSRF và endpoint thật.
Service/repository dùng một transaction SQL ngoài; từng thao tác có savepoint.
Mọi dữ liệu giả rollback khi kết thúc; executor owned COMMIT chưa được chạy.
Cookie auth/CSRF HttpOnly/Secure/Strict; browser chỉ giữ context/token request trong RAM.
Kiểm signup, bảy vai trò, logout/tabs/profile, password và Admin lock/replay/lookup.
Mất response được gây sau xử lý thật; không tự gửi lại và404 không chứng minh rollback.
Mỗi nhóm đóng browser/listeners, SQL baseline trước/sau phải giữ nguyên.
Đây là integrated fixture proof; principal/profile/PKI production và full V01 còn thiếu.
